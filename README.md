# 🔐 RSA Secret Message CLI Tool

A simple command-line based project that uses **RSA Encryption Algorithm** to securely send and receive secret messages.

## 📌 Overview

This project demonstrates how public-key cryptography works using the RSA algorithm. It allows users to encrypt and decrypt messages through the command prompt (CMD), ensuring secure communication.

## 🚀 Features

* 🔑 RSA key generation (Public & Private keys)
* 🔒 Message encryption using public key
* 🔓 Message decryption using private key
* 💻 Easy-to-use Command Line Interface (CLI)
* 🛡️ Secure communication concept demonstration

## ⚙️ How It Works

1. Generate RSA keys (public & private)
2. Encrypt a message using the public key
3. Share the encrypted message
4. Decrypt using the private key
